# Security Policy

## Supported versions

This project has no release yet. Security fixes go into the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Report it privately through
GitHub:
[Security → Report a vulnerability](https://github.com/machine-made/liblinear-rs/security/advisories/new).

Please include:

- the `liblinear-rs` version or commit,
- the input that causes the problem,
- the command or API call you ran, and what happened.

Ricardo Frantz reads the reports.
